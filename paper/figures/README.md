# Paper figures

The figures used by the paper are generated by `python scripts/evaluate.py` into
`results/figures/`, at 200 dpi. This directory holds the copies referenced by
`paper/outline.md`.

| `fig05_rmse_comparison.png` | Results 1 — RMSE by model |
